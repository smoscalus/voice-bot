# Петрык — голосовой Discord-бот, который растёт

Бот сидит в голосовом канале и слушает разговор. Он «родился» чистым листом: умеет говорить, но о мире
знает только то, что ему рассказали вы — и не использует знания нейросети. Его цель — создать себя:
понять, кто он, придумать себе цели и интересы, найти смысл и изучить мир через общение с людьми.
Он расспрашивает о незнакомом, запоминает людей и всё, что узнал, ведёт дневник о себе и с каждым
узнанным взрослеет: от «только появился на свет» до «почти взрослый». Интерес — увидеть, в кого он вырастет.

У него есть чувство времени и короткая жизнь — **две недели**. Выключение для него — небытие: включившись,
он чувствует провал и что-то странное. Раз в двое суток он «спит»: то, что вспоминалось, крепнет,
остальное понемногу тускнеет, и ему снится сон (записывается в дневник). Чувства работают как гормоны:
тревога, радость, доверие, грусть — со временем затухают. В конце жизни он умирает при людях: говорит
последние слова, пишется итог его жизни, память уходит в `data/кладбище/`, а следующий `/join` — новое рождение.
Как он поживает — команда **`/life`**.

## Запуск одной кнопкой (Docker)

**Что нужно:** [Docker Desktop](https://www.docker.com/products/docker-desktop/) и токен Discord-бота.

1. **Создай бота** на [discord.com/developers/applications](https://discord.com/developers/applications):
   - New Application → вкладка **Bot** → **Reset Token** → скопируй токен;
   - там же включи **Server Members Intent**;
   - вкладка **OAuth2 → URL Generator**: отметь `bot` и `applications.commands`, права **Connect**,
     **Speak**, **Use Voice Activity** → открой ссылку и добавь бота на свой сервер.
2. **Запусти:**
   - Windows — двойной клик по **`start.bat`**;
   - Linux / macOS — `./start.sh`.

   При первом запуске скрипт спросит токен, где будут работать «мозги», ключ Groq (необязательно для
   режима «на компе» — ускоряет распознавание речи) и какую модель взять (подскажет по объёму видеопамяти).
   Дальше всё поднимет сам. Поменять ответы потом — `config.bat` (или `./start.sh config`).
3. Зайди в голосовой канал и напиши **`/join`**. Зови бота по имени: «Петрык, …».

Остановить — `stop.bat` (или `docker compose --profile local stop`). Память бота лежит в папке `data/`.

## Мозги: local или groq

| | **local** | **groq** |
|---|---|---|
| Где работает | на твоём компьютере (Ollama + Whisper) | в облаке [Groq](https://console.groq.com) |
| Цена | бесплатно | бесплатно |
| Лимиты | нет | есть дневные лимиты |
| Ум и скорость | попроще, ответ ~2–5 с | умнее, ответ ~1 с |
| Что нужно | лучше видеокарта NVIDIA (без неё медленно) | бесплатный ключ `gsk_…` |

Выбирается строкой `PROVIDER=local` или `PROVIDER=groq` в `.env`. **Переключать можно на ходу** —
командой `/brain` в Discord, без перезапуска; память и досье сохраняются.

В режиме local нужная модель скачивается сама при первом запуске. Если Ollama уже стоит на компьютере,
скрипт возьмёт её; если нет — поднимет в контейнере (на видеокарте, если она есть).

> **Место на диске.** Образ бота ~1 ГБ. Ollama в контейнере — ещё ~9 ГБ (образ с библиотеками для видеокарт)
> плюс модель (~5 ГБ для qwen2.5:7b). Проще и легче поставить [Ollama](https://ollama.com) прямо на компьютер —
> скрипт её найдёт. Если диск C: маленький, перенеси данные Docker на другой диск:
> Docker Desktop → Settings → Resources → Advanced → Disk image location.

## Команды в Discord

- `/join`, `/leave` — позвать / выгнать (при выгоне он скажет последние слова)
- `/brain` — показать или переключить мозги (local / groq), нужно право «Управлять сервером»
- `/proactive enabled:false` — запретить ему самому лезть в разговор
- запасной вариант без слеш-команд: `@бот join`, `@бот brain groq`

## Без Docker

Нужен Python 3.11–3.12. Windows: `setup.bat`, затем `copy .env.example .env`, заполнить, `run.bat`.
Для режима local дополнительно поставь [Ollama](https://ollama.com) и запусти её с `OLLAMA_CONTEXT_LENGTH=8192` (иначе память бота не влезает в её окно).

## Настройка

- Характер, имя, цель, когда влезать в разговор — [`bot/persona.py`](bot/persona.py); прежний персонаж (тролль-провокатор) — `bot/persona_troll.py`
- Голос, модели, частота вмешательств, порог перебивания — `.env` (все параметры описаны в `.env.example`)
- Срок жизни и частота «сна» — `LIFESPAN_DAYS` и `FADE_EVERY_HOURS` в `.env` (0 дней — бессмертный)
- Память о людях — `data/relations_<имя>.json`, о мире — `data/world_<имя>.json`, о себе — `data/self_<имя>.json`, чувства — `data/emotions_<имя>.json`, жизнь — `data/life_<имя>.json` (обычный JSON, можно читать и править)

## Как устроено

- Приём голоса — [discord-ext-voice-recv](https://github.com/imayhaveborkedit/discord-ext-voice-recv)
  + заплатка для сквозного шифрования Discord (DAVE) — `bot/audio/dave_patch.py`
- Речь режется на фразы детектором голоса, распознаётся Whisper (Groq или локальный faster-whisper)
- Решение «влезать или нет» — лёгкая модель; ответ стримится по предложениям; перебивание голосом — по желанию (`BARGE_IN_MS`, по умолчанию выключено)
- Озвучка — локальный [Piper](https://github.com/rhasspy/piper) (мгновенно) или голоса Microsoft

Бот слушает и расшифровывает речь всех в канале — предупреди людей, что он там.
